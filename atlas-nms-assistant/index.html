ATLAS ACTIVATION

Enter your Anthropic API key to activate ATLAS.
The key is stored only on this device.

VOICE CHARACTER shapes any voice; its deep Atlas resonance needs the optional ElevenLabs key. A pasted voice ID overrides the character's own voice (add the voice to My Voices in your ElevenLabs account first), while the character keeps shaping its tone.

Create a key free at console.anthropic.com, then add a small prepaid credit there (even $5 lasts months — a chat costs a penny or two). Note: this is separate from any Claude.ai subscription. The key is sent only to Anthropic and stored only on this device.

⚠ Keep your key private, like a password. A typical chat costs only a penny or two, and you can set spending limits — or revoke the key — anytime at console.anthropic.com.

ATLAS is a free, unofficial fan project — its creator receives no money whatsoever. The only cost is your own Anthropic API usage, billed by Anthropic to you directly. No Man's Sky © Hello Games.

WELCOME, TRAVELLER

Everything here is free to use, forever.
Tap the orb or the mic and speak — the Atlas answers aloud with the lore of the No Man's Sky universe. No account, no cost.

To unlock the Atlas's FULL AI potential — true conversation about anything — tap the ⚙ cog (top right) and add your own Anthropic API key. The cog is also where you choose the Atlas's voice.

UNLOCK LIVE DATA

ATLAS can now search the web — real weather, current news, live stats — not just No Man's Sky lore. One extra setting is needed first.

Go to platform.claude.com/settings/privacy, sign in with the same account as your API key, and switch on Web Search. This is separate from claude.ai's own settings, and it's per-account — if a friend uses ATLAS with their own key, they'll need to enable it too.

Web search is billed by Anthropic at roughly $10 per 1,000 searches, on top of normal chat usage — charged to whoever's key is entered.

ATLAS MEMORY

What the Atlas remembers about you between visits. It learns from what you tell it about yourself; you can add, remove or wipe anything here.

    Stored only in this browser. With an API key, your memories go to Anthropic with your own chats so the Atlas can use them, and a tiny extra request (a fraction of a penny) checks new messages for things worth remembering.
